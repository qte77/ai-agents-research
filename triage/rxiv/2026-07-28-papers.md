## Extracts

### Robot-Factored World Models via Robot Rendering

- arxiv: <https://arxiv.org/abs/2607.22535>
- summary: The study introduces robot-factored world models that improve action-conditioned video predictions by separating action realization and robot rendering from the world model.
- methods: action realization, robot rendering, camera-aware static RGB/depth context
- findings: The rendered interface outperforms vector-conditioned baselines; The model generalizes to unseen robot embodiments; The model can generate robot manipulation videos from human demonstrations

### ViTacWorld: Scaling Visuo-Tactile World Models for Contact-Rich Robot Manipulation

- arxiv: <https://arxiv.org/abs/2607.22530>
- summary: ViTacWorld is a novel action-conditioned visuo-tactile world model designed to enhance scalable contact-rich robot manipulation by leveraging public tactile datasets and a simulation environment.
- methods: pretraining with real and simulated visuo-tactile trajectories, finetuning with real-world policy rollouts, predicting temporally aligned visual observations and tactile feedback
- findings: ViTacWorld generates physically meaningful rollouts; improves policy performance through scalable data augmentation; enables action-conditioned policy evaluation

### Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills

- arxiv: <https://arxiv.org/abs/2607.22529>
- summary: The study introduces Skill Self-Play (Skill-SP), a co-evolutionary framework that reconciles the tension between task diversity and verification reliability in LLM training through dynamic routing of agent skills.
- methods: reinforcement learning, co-evolutionary framework
- findings: Skill-SP effectively bridges the gap between structured verification and open-ended exploration.; Empirical evaluations demonstrate that Skill-SP consistently pushes the performance ceiling of competent backbones.; Skill-SP catalyzes striking turnarounds for initially misaligned models.

### The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents

- arxiv: <https://arxiv.org/abs/2607.22520>
- summary: The study evaluates the impact of procedural skills on LLM agents, revealing that while skills can improve task success, they can also lead to regressions, highlighting the need for a nuanced evaluation approach.
- methods: comparison of agents with and without skills, analysis of regression and residual failure, evaluation of grounding and verification
- findings: Regressions are substantial, with the best performing skills regressing less rather than gaining more.; Three causes of regression were identified: skill description osmosis, grounding displacement, and verification displacement.; Existing skills often overemphasize procedural guidance while under-supporting grounding and verification.; Many regressions and persistent failures can be recovered through better grounding and verification.

### CausalForge: A Formally Grounded, Self-Improving Agentic Framework for Automated Research in Causal Inference

- arxiv: <https://arxiv.org/abs/2607.22511>

- methods: automated theoretical research, machine-checked proofs, statement audit
- findings: LLM reviewers are empirically unreliable; CausalForge augments kernel verification with a statement audit

### MineValiCoder: Reliable Code Generation with Test Case Quality Mining and Bipartite Graph-Based Mutual Validation

- arxiv: <https://arxiv.org/abs/2607.22471>
- summary: MineValiCoder is a collaborative closed-loop TDD framework that enhances automated code generation by improving test-case quality and code quality through mutual validation.
- methods: Test Case Quality Mining, Parallel TDD Refinement, Bipartite Graph-Based Code-Test Mutual Validation
- findings: MineValiCoder significantly outperforms state-of-the-art methods.; Achieves Pass@1 scores of 96.34% on HumanEval, 87.40% on MBPP, 64.00% on APPS, and 51.33% on LiveCodeBench.; Mitigates LLM stochasticity and improves the reliability of automated code generation.

### TRACE-ROUTER: Task-Consistent and Adaptive Online Routing for Agentic AI

- arxiv: <https://arxiv.org/abs/2607.22465>
- summary: TRACE-Router is a task-level routing framework that improves the accuracy-latency trade-off for large language models by using a contextual bandit approach to assign tasks to models based on delayed feedback.
- methods: contextual bandit, task-level routing
- findings: TRACE-Router improves the accuracy-latency trade-off across three agentic benchmarks.; On tau2-Bench, it outperforms latency-matched interpolation between individual models by 7-8 accuracy points.; On Terminal-Bench, it achieves 7.1 higher accuracy points than the strongest single model baseline with 36% lower latency.

### Dynamic Capability Scoping for Enterprise AI Agents: A Synthetic Dataset and Three-Source Permission Architecture

- arxiv: <https://arxiv.org/abs/2607.22445>
- summary: The paper proposes a dynamic least-privilege architecture for enterprise AI agents to reduce over-privilege and enhance security, supported by a synthetic dataset for evaluation.
- methods: three-source architecture, role-based ceilings, task-context classifier, policy-derived combination prohibitions, two-pass pipeline
- findings: Synthetic prompt generation can drive policy refinement.; The dataset reduced ceiling violations from 46 to 3, a 93% reduction.; The architecture supports both enforcing and observe-only deployment.

### On the Identifiability of Controlled World Models

- arxiv: <https://arxiv.org/abs/2607.22430>
- summary: This study establishes a joint identifiability theory for controlled world models with Gaussian latent states and identifies conditions for representation and transition identifiability under state-dependent behavior policies.
- methods: joint identifiability theory, quantitative bounds derivation, predictor perturbations construction
- findings: Spectral separation of the predictable signal governs representation identifiability.; Non-degenerate conditional action variation governs transition identifiability.; Every global minimizer of the JEPA objective identifies the latent state and controlled transition up to an orthogonal transformation.; Counterfactual-to-on-policy error ratio reveals the cost of limited action coverage.

### Conformal Constraint Tightening for Chance-Constrained Motion Planning with Unknown Dynamics

- arxiv: <https://arxiv.org/abs/2607.22409>
- summary: This letter presents a planner-agnostic constraint-tightening procedure that enhances existing motion planning algorithms with probabilistic task-completion guarantees for systems with unknown dynamics.
- methods: conformal prediction, constraint-tightening procedure
- findings: Provides probabilistic task-completion guarantees on the true system; Empirical validation shows improved task completion relative to nominal-model planning

### A Self-Calibrating Agentic AI Framework for Autonomous Edge Resource Allocation

- arxiv: <https://arxiv.org/abs/2607.22400>
- summary: This study proposes and evaluates a self-calibrating agentic AI framework that enhances the reliability of LLM-driven systems in open-ended environments by mitigating operational drift and approximating ground truth.
- methods: self-calibration mechanism, ARIMA forecaster
- findings: The proposed framework achieves 91.7% higher accuracy for resource usage prediction compared to baseline LLM agents.; The prediction speed improves by 71.7% compared to pure profiling.; Ground truth generation using the ARIMA leaping algorithm is 52% faster than a standard ARIMA forecasting algorithm while maintaining the same accuracy.

### SceneActBench: Can Agents Act on the 3D Scenes They See?

- arxiv: <https://arxiv.org/abs/2607.22393>
- summary: SceneActBench is a benchmark designed to evaluate visually conditioned actions of vision-language model agents in multi-object 3D scenes across five tasks.
- methods: benchmarking, evaluation against hidden ground truth, task-specific geometric metrics
- findings: Overall scores span 38.6-50.2 across eleven proprietary VLM configurations; No VLM configuration performs consistently well across tasks; Failures manifest in specific areas of the tasks

### HiKV: Hierarchical Importance-Aware KV Cache with Hardware Acceleration for LLM Decoding

- arxiv: <https://arxiv.org/abs/2607.22389>
- summary: HiKV is a novel algorithm-hardware co-design that addresses the memory bottleneck of KV cache in long-context large language models by compressing the cache and utilizing a dedicated accelerator.
- methods: hierarchical importance awareness, cache compression, importance sorting
- findings: achieves up to 7.95x speedup; 90% energy reduction in attention computation; negligible 1% accuracy loss; 1.82~4.87x reduction in external memory accesses; adds only 8% to the system area

### Agentic Root Cause Analysis through Evidence-Grounded Reasoning

- arxiv: <https://arxiv.org/abs/2607.22385>
- summary: AgentRCA is a zero-shot agentic framework that combines a data-driven digital twin with a tool-augmented large language model for evidence-grounded root cause analysis in industrial operations.
- methods: inference-time reasoning, statistical evidence gathering, hypothesis evaluation
- findings: AgentRCA achieves diagnostic performance competitive with fully supervised baselines.; It does not require fault-specific training.; It produces transparent reasoning traces linking symptoms to physical causes.

### IDEAgent: Agentic Quality-Diversity Search for Research Idea Generation

- arxiv: <https://arxiv.org/abs/2607.22375>
- summary: This work introduces IDEAgent, a multi-agent framework that enhances research ideation by simultaneously optimizing for Quality and Diversity in scientific discovery.
- methods: multi-objective feedback, lightweight sequential memory, explicit comparison
- findings: IDEAgent outperforms the best baseline by 3.89x on Yield; IDEAgent achieves non-zero Yield on 8x more topics; Repair and refinement are crucial for building logical rigor and clarity while preserving non-obviousness
