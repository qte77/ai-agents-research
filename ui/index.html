ai-agents-research

Field research and feature analysis for AI coding agents — sandboxing, orchestration, plugins, community tooling, SDLC patterns.

A continuously-updated research catalog: make informed adopt / trial / assess / hold decisions about coding agents and their ecosystems before building production systems on them. Tracks Claude Code, JetBrains Air, DeerFlow, Goose, Codex, Devin and others — plus the surrounding plugins, observability, SDLC patterns, and cross-repo learnings.

Each doc opens with frontmatter (a status ring, dates, a one-line purpose; see the schema), a What It Is section, and ends with a Sources table. Docs are grouped by folder and by topic hub. Scheduled workflows keep it current: Claude Code changelog, status and community monitors, a link-rot check, an M365 drift check, a plan reconcile and a weekly paper triage.
